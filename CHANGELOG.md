## [Unreleased]

### Added

- Initial SDK release covering ActiveCampaign API v3
- Typed models for all API resources
- Automatic retry with backoff on rate-limited requests
- Pagination support
- Resources: Contacts, Deals, Tags, Lists, Accounts, Automations, Campaigns, Webhooks, Custom Fields, Notes, Forms, Segments, Users, Addresses
- Deal resources: Pipelines, Stages, Custom Fields, Roles, Tasks, Task Types, Task Outcomes
- Account resources: Account Contacts, Custom Fields, Custom Field Values
- Contact field resources: Field Values, Field Options
- Communication resources: Messages, Scores
- Admin resources: Groups, Calendar Feeds, Brandings, Saved Responses, Templates, Settings
- E-Commerce resources: Connections, Customers, Orders, Order Products
- Tracking resources: Event Tracking, Site Tracking
- Custom Objects: Schemas, Records
